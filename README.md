# F1 Race Controller

基于 yahyio/phone-wheel 的中文定制界面，添加原生 Core Haptics、Core Motion 和局域网 WebSocket 桥接。

## 当前状态

原生版已完成多版云端编译，用户已确认局域网连接与游戏遥测可用。Windows 服务支持 2025 和 2026 两种 UDP 格式；最新变更见下方版本记录。

## 0.4.0 工业座舱与自适应转向

- 木瓜橙、石墨色仪表与高亮红绿踏板，重新统一边框、圆角、刻度和对齐线。左侧升降挡竖排，方向键扩大触摸范围；Y/B 与左看、后视、右看组成整齐的功能区。
- 左右看分别发送右摇杆 X 轴，后视保留右摇杆 Y 轴；与陀螺仪左摇杆转向独立。左右同时按下时 X 归零。电脑服务也需要使用本次新增 ll/lr 字段的版本。
- 删除“游戏内辅助”说明选项，新增轻／标准／强三档自适应：随新鲜车速收柔中心细修，大角度保留直接响应与完整满舵。只渐变车速系数，不给转角再加时间滤波；遥测过期自动平缓退回基础响应。这是输入稳定辅助，不会判断路线或自动过弯。
- 背景震动强度参数从 0.12 提至 0.20；路肩采用 90ms 强震、25ms 间隔、105ms 强震的低锐度双段触感。满转角持续提示保留，压路肩时短暂降低其力度，避免屏蔽路肩；菜单／后台／断线会停止震动。
- CI 增加隔离的 WebKit 手机尺寸布局与触摸区域检查，截图使用示例遥测。实体手机触感及游戏改键仍需实际试用。

不需要付费 Apple 开发者会员；免费账号签名通常需要每 7 天续签。构建不需要任何 Apple 密码、签名证书或 GitHub Secrets。

## 云端构建

1. 创建自己的 GitHub 仓库，把本目录内容放在仓库根目录。必须保留 `.github/workflows/build-ios.yml`。
2. 仓库 Actions 中选择 **Build iPhone app**，点击 **Run workflow**。
3. 等待成功后，从该运行的 Artifacts 下载 **PhoneWheel-unsigned**，解压得到 `PhoneWheel-unsigned.ipa`。
4. 编译失败则下载 build-log。不要把未成功构建的源码当作可安装应用。

GitHub 公共仓库标准 macOS runner 免费；私人仓库按账号额度计算。项目只手动构建，不设置定时任务。

## Windows 安装

从 https://sideloadly.io/ 下载 Windows 版 Sideloadly，按其要求准备 Apple 设备驱动。

连接 iPhone，由用户在手机上确认信任电脑。把 IPA 放入 Sideloadly，通过用户自己的免费 Apple 账号签名安装。账号、密码和验证码由用户在本机操作，不要放进仓库。

按手机提示启用开发者模式、信任开发者；约每 7 天需要重新签名。第三方安装工具的实际兼容性需现场确认。

## 使用

1. 电脑启动 Phone Wheel 服务，手机和电脑在同一个可信局域网，代理应绕过局域网。
2. 打开 App，输入电脑 IPv4 和端口，例如 `192.168.1.10:8080`。
3. 首次连接将展示电脑证书 SHA-256。与电脑证书指纹核对一致后再信任；证书改变会重新提示。
4. 横屏握稳后点击开始驾驶，自动以首次传感器读数校准中心。
5. **控制器设置** 中独立管理网络连接、震动、中心校准和转向范围；**返回驾驶** 关闭设置，**结束驾驶** 才返回初始界面。游戏暂停为独立 Xbox Start 键。
6. 收到游戏遥测时显示实际档位、速度、DRS 状态和 15 段转速灯；数据过期显示等待，不显示模拟档位。

震动包括按键轻触、换挡、转速阈值和 DRS 提示。游戏遥测需正常运行，才能触发相应游戏状态反馈。支持遥测路肩提示、踏板与轻背景震动；不等同于实体方向盘力反馈。

页面在 App 内本地加载；原生层连接局域网电脑。无外部账号、分析或数据上传。App 只允许连接私人 IPv4 地址，不开放网页对任意外部服务器的原生通信。

## 界面版本

使用最新中文网页：左右踏板均 60% 高度、十字方向键靠左、矩形功能键含彩色圆形 ABXY 图标、肩键标注、转向显示条。已删除满油锁定；左侧刹车上方为全刹车按钮，右侧油门上方为满油按钮，按住生效、松手归零。

## 0.3.0

升挡在上、降挡在下并靠近左手，方向键和常用赛车功能集中在左侧与中部；右手保留油门操作区。
原生连接使用 Network.framework 的加密 WebSocket，按用户明确确认的 SHA-256 校验局域网电脑证书，并自动回复 Ping。不会切换到明文连接。

## 0.3.1 传感器处理

使用 Core Motion 融合重力与旋转速率，自适应滤波按传感器时间间隔计算；六帧校准、过期数据归零、接近平放时忽略不可靠角度并在抬起后衔接，结束驾驶后停止传感器采集。

## 0.3.2 低延迟转向

降低小幅转向的滤波滞后，传感器目标频率 100 Hz，每次收到新传感器数据即发送摇杆值；视觉刷新单独进行，移除方向盘图标的过渡动画。触摸踏板的数值不会被转向更新重置。

## 0.3.3 按键位置

将超车 LB 和无线电 RB 移到左上方并排；向后看移到原超车的位置，保留低延迟转向更新。

0.3.5：开始页、网络连接设置提醒关闭 iPhone VPN/代理；54、超时及 TLS 错误附带 VPN 检查提示，不尝试控制其他 App 的 VPN。


0.3.6：使用玩家四轮 surface_type=1 的真实路肩遥测生成纹理震动，车速低于 5 km/h 或数据过期时关闭；油门轻震、刹车反馈随输入增强，所有效果共用震动开关。满油／全刹车按钮加高，保留按住生效、松手归零。


0.3.7：可选关闭、高速稳定响应，以及 F1 25 官方游戏内转向辅助的设置指引。稳定模式随实时车速收柔中心响应，无新增时间滤波，满转向仍输出 100%。游戏内辅助选项仅提供指引，不声称已更改或验证游戏开关。


0.3.8：加宽两侧模拟踏板、放大满油与全刹车按钮，顶栏菜单向中央收拢；连接状态独立放在底部并可点击看详情。设置菜单改为固定高度三列卡片，一屏保留全部常用操作，无滚动。


0.3.9：真实路肩遥测到来时，直接触发独立的双脉冲与短连续震动，保留转瞬即逝的路肩触感；持续压路肩时有节流地重复，震动开关、菜单、后台和断线可停止。

震动设置新增“测试路肩震动”，可独立验证路肩触感，不必先在赛道触发。


0.3.10：有效遥测时加入很轻的背景震动，停止遥测或退出驾驶后归零；达到当前满转向角度时触发一次独立提示，回收至 88% 以下再触发。满转向提示与路肩双脉冲可分别测试，均遵守总震动开关。沿用已确认的 0.3.8 界面。

0.3.11：满油和全刹车按钮向上加高，底边与踏板之间的间隔不变，保留一屏设置菜单。路肩改为加强版满转向触感：0.14 秒低锐度连续震动，力度 0.90–1.00；移除叠加的尖锐路面层，并短暂压低踏板／背景震动以凸显路肩。满转向提示仍优先，后台、菜单及断线停止逻辑保留。实际触感需安装后在手机验证。


## 0.3.12 木瓜橙座舱与触摸操作

- 木瓜橙与深炭黑主题，保留已确认的布局和按钮尺寸；红刹车、绿油门、彩色 ABXY 保留，按下高亮不再改变按钮位置。
- 顶部全刹车／满油标明 LT／RT，发送完整扳机值，可用于游戏菜单翻页。长条继续按触点位置控制模拟输入。
- 按键即时发送；按住油门时可独立换挡。同键多指追踪、模拟踏板指针归属、松手立即归零；菜单及断线统一清空控制，返回时需重新按下。
- 有界原生队列保留按键与踏板接触／释放边沿，合并连续轴更新，避免最新快照合并丢失短按。预构建加入纯 Swift 回归测试。
- 油门持续震动增强并加入触按提示；遥测有效时提供轻背景震动。测试入口先播放背景、短暂停顿后播放油门触感。
- 达到设定满转角后持续震动，回收至 97% 以下停止；每 80ms 更新存活状态，丢失更新 250ms、退出驾驶、后台、断线或总开关关闭时停止。

触感强弱与游戏菜单翻页效果仍需更新后在手机和游戏验证。
